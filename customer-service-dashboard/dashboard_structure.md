Northstar Customer Support Dashboard Structure

1. Home Page

Purpose: Allow the customer to choose what they need help with.
Options:

- Check Order Status
- Returns & Refunds
- Contact Support

2. Order Status Page

Purpose: Allow a customer to check the status of an order.
Features:

- Enter order number
- Check order status
- Display status:
  - Processing
  - Shipped
  - Out for Delivery
  - Delivered

3. Returns & Refunds Page

Purpose: Help customers understand whether they can return an item and what to do next.
Features:

- Start a return
- Answer eligibility questions
- Display return instructions
- Display refund information

4. Help/Escalation Section

Purpose: Direct unresolved issues to customer support.
Feature:

- Contact Customer Support

Customer Flow

Home
→ Choose Order Status or Returns & Refunds
→ Complete the required steps
→ Receive an answer
→ Contact Support if the issue cannot be resolved
